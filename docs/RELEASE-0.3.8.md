# Release 0.3.8

## Grade average simulator

- Include whole-number, decimal, plus and minus grades from ordinary grade entries.
- Use an explicit half-point convention for plus/minus marks (for example, 4+ = 4.5 and 4- = 3.5).
- Explain that schools may apply their own rules and that the simulator is an unweighted estimate.

## Upgrade

This release keeps the existing application ID and stable release signing configuration. Install it over the existing signed release; do not uninstall the app to update.
