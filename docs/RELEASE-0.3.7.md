# Release 0.3.7

## Agenda and personal events

- Keep the monthly calendar as the primary agenda view; remove the duplicate school-event list below it.
- Show school and personal events when their date is selected.
- Validate personal event dates as strict ISO calendar dates and reject impossible dates or trailing text.

## Upgrade

This release keeps the existing application ID and stable release signing configuration. Install it over the existing signed release; do not uninstall the app to update.
